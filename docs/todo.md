# Vintly 후속 작업

출시 전까지 놓치면 안 되는 작업만 기록한다.

## 앱 식별자

Android 출시 식별자는 `com.vintly.app`으로 확정했다. iOS는 아직 개발용 식별자 `com.example.vintlyApp`을 사용한다.

- [x] Android 식별자를 최종 값 `com.vintly.app`으로 변경한다.
- [ ] 출시 전 iOS 식별자를 최종 값으로 변경한다.
- [ ] 식별자 변경 후 네이버 클라우드 Maps의 Android 패키지명과 iOS Bundle ID도 갱신한다.
- [ ] Android와 iOS 실제 기기에서 네이버 지도 인증을 다시 확인한다.

## 네이버 지도

- [x] 환경별 로컬 설정에 네이버 Maps Client ID 입력 공간 추가
- [x] `flutter_naver_map` 적용 및 기존 지도 교체
- [ ] 네이버 클라우드 콘솔에서 일별·월별 호출 한도 설정
- [ ] Android 실제 기기에서 지도, 마커 선택, 상세 화면 확인
- [ ] iOS 환경에서 네이버 지도 네이티브 의존성 설치 및 실제 기기 확인

선택 배경은 [네이버 지도 ADR](decisions/0001-use-naver-map.md)을 참고한다.

## 인증

- [ ] 로그인 성공 응답에서 access 토큰이 없으면 홈으로 이동하지 않고 오류 처리
- [ ] 회원가입 성공 판정을 HTTP 상태와 `success` 필드까지 허용하도록 보완
- [ ] 로그인 화면에서 내부 예외 문구 대신 일관된 한국어 오류 메시지 표시
- [x] 회원가입의 안내를 이메일 인증 흐름에 맞게 수정
- [x] 회원가입에 만 14세 이상 및 이용약관·개인정보처리방침 필수 동의 추가
- [x] 로그인·회원가입·마이 화면에 이용약관·개인정보처리방침 공개 URL 연결
