# ADR 0001: 빈티지샵 탐색에 네이버 지도 사용

- 상태: 채택
- 결정일: 2026-08-27

## 배경

Vintly는 한국의 20~40대 빈티지 관심 사용자를 위한 모바일 앱이다.
핵심 경험 중 하나는 지도에서 국내 빈티지 숍을 탐색하고 마커를 눌러 상세 정보를 확인하는 것이다.

기존 구현은 `flutter_map`과 CARTO 지도 타일을 사용한다. 구현이 단순하고 별도의 지도 인증이 필요하지 않다는 장점이 있지만, 국내 지명과 도로명 표기가 한글로 일관되게 제공되지 않는다. 한국 사용자를 대상으로 하는 지역 기반 탐색 화면에서는 자연스러운 한글 지도와 국내 지도 정보의 품질이 더 중요하다.

## 결정

빈티지샵 탭의 기본 지도를 네이버 지도의 `Dynamic Map`으로 교체한다.

Flutter 연동에는 네이버 Android/iOS 지도 SDK를 연결하는 `flutter_naver_map` 패키지를 사용한다. 정확한 패키지 버전은 도입 시점의 Flutter 및 플랫폼 호환성을 확인한 뒤 고정한다.

네이버 Maps Client ID는 소스 코드나 Git 추적 파일에 직접 기록하지 않고 환경별 로컬 설정으로 주입한다.

## 선택 이유

- 국내 지명, 도로명, 건물 및 교통 정보가 한국어로 자연스럽게 표시된다.
- 주요 사용자인 한국 사용자에게 익숙한 지도 경험을 제공한다.
- 국내 매장 탐색에 필요한 지도 데이터의 정확성과 갱신 품질이 높다.
- 마커, 카메라 이동, 줌, 화면 영역 맞춤 등 현재 기능에 필요한 동적 지도 기능을 지원한다.
- 지도 위에 Vintly 서버에서 받은 빈티지 숍 마커를 직접 표시할 수 있다.
- 월 무료 호출량이 제공되어 초기 서비스 규모에서 비용 부담이 낮다.
- 네이버 클라우드 콘솔에서 사용량과 호출 한도를 관리할 수 있다.

## 검토한 대안

### flutter_map과 공개 지도 타일 유지

장점은 구현이 간단하고 공급자 SDK에 대한 의존성이 낮다는 것이다. 그러나 국내 지역명의 한글 표기가 일관되지 않고, 한국 사용자 대상 매장 탐색 경험의 품질이 충분하지 않아 선택하지 않았다.

### Google Maps

공식 Flutter 패키지와 플랫폼 지원이 강점이다. 반면 결제 계정과 플랫폼별 API 키 설정이 필요하며, Vintly의 국내 매장 탐색 경험에서는 네이버 지도가 사용자 친숙도와 국내 지도 정보 측면에서 더 적합하다고 판단했다.

### 카카오 지도

국내 지도 품질과 사용자 친숙도는 충분하다. 다만 지도 기능을 위한 공식 Flutter 연동 경로가 네이버 지도용 커뮤니티 패키지보다 불명확하고 네이티브 브리지 유지보수 부담이 커질 수 있어 이번에는 선택하지 않았다.

## 영향과 제약

- 네이버 클라우드 Maps 애플리케이션과 Client ID가 필요하다.
- Android 패키지명과 iOS Bundle ID를 네이버 클라우드에 등록해야 한다.
- 현재 임시 앱 식별자를 출시용으로 변경하면 네이버 Maps 설정도 함께 갱신해야 한다.
- `flutter_naver_map`은 네이버가 직접 배포하는 공식 Flutter SDK가 아닌 커뮤니티 패키지이므로 버전 호환성과 유지보수 상태를 지속적으로 확인해야 한다.
- Android/iOS 네이티브 지도 SDK의 최소 OS 버전과 빌드 설정을 충족해야 한다.
- 지도 공급자 장애, 인증 실패, 사용량 초과 상황에 대한 사용자 오류 상태가 필요하다.
- 호출량과 요금 정책은 변경될 수 있으므로 출시 전과 운영 중에 공식 요금표를 다시 확인한다.

## 구현 원칙

- 기존 빈티지 숍 API 계약과 좌표 모델은 변경하지 않는다.
- 기존 마커 선택, 상세 바텀시트, 좋아요 및 댓글 흐름을 퇴행시키지 않는다.
- 지도 Client ID나 기타 비밀·환경값을 로그 또는 저장소에 남기지 않는다.
- 환경값 누락과 인증 오류를 조용히 무시하지 않고 한국어 오류 상태로 표시한다.
- 도입 후 Android와 iOS 실제 기기에서 각각 검증한다.
